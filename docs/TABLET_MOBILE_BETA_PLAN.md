# Serverless Tablet / Mobile Beta 개발안

갱신: 2026-11-19 KST · 버전: **v0.1.0-beta.1** · 상태: 구현 및 Beta 검수

## 제품 목표

**prompt token saver : 토큰을 아끼세요**

무료로 공개할 한 화면 도구다. 태블릿·모바일 브라우저에서 원문을 붙여넣고 요약을 두 번 거친 뒤 Drive에 저장한다. 비용이 드는 추가 AI 작업은 사용자가 결과를 복사해 원하는 서비스에서 직접 수행한다.

| 항목 | 내용 |
|---|---|
| 존재 이유 | 언제 어디서든 돈과 발열 걱정 없이 생각을 모으고 다듬는 가장 가벼운 전초기지 |
| 비용 구조 | 유지비·API 비용 0원 — 무료 정적 호스팅 + 온디바이스 연산 |
| 핵심 구성 | 태블릿 + GitHub Pages + LiteRT-LM (`Gemma`) + 브라우저 유사도 검색 |
| 주요 임무 | 이동 중 아이디어·메모 수집, 놀람성 기반 압축 요약, 로컬 벡터 검색, 선택 GitHub 백업 |

핵심 역할의 목표와 현재 Beta 구현은 구분한다. 발열 0을 보장하지 않는다. 실제 놀람성·임베딩 검색·개인 자료 GitHub 백업은 후속 구현이며 지금 지원하는 것처럼 표시하지 않는다. GitHub 백업은 사용자가 선택한 자료·대상만 명시적으로 승인한 뒤 구현한다.

## 화면과 동작

```text
prompt token saver : 토큰을 아끼세요                    Beta

제목 [                         ] [Drive 가져오기] [파일]

┌──────────────────┬──────────────────┬──────────────────┐
│ 원문 붙여넣기    │ 요약 1    [복사] │ 요약 2    [복사] │
│                  │                  │                  │
│                  │                  │                  │
└──────────────────┴──────────────────┴──────────────────┘

      [요약하기 1] → [필터로 요약하기 2] → [Drive 저장]

저장 목록                                    [불러오기]
┌─────────────────────┬───────────────────┬─────────────┐
│ 제목                │ 저장·수정 시각    │ 열기        │
└─────────────────────┴───────────────────┴─────────────┘

▸ 설정
```

태블릿 가로는 세 칸을 나란히, 모바일·좁은 세로 화면은 세 칸을 위아래로 배치한다. 별도 홈·소개·결과 화면·사이드바·그래프는 만들지 않는다. 기본은 다크 모드이며 별도 테마 전환 기능을 추가하지 않는다.

| 디자인 항목 | 기준 |
|---|---|
| 배경 | 어두운 네이비 `#0b1017` |
| 입력·결과 영역 | 어두운 패널 `#151d29`, 선 `#2b3646` |
| 본문 | 밝은 회색 `#e2e8f0`, 실제 입력/요약 14~15px |
| 주 실행 버튼 | 밝은 파랑 `#7aa2f7`, 분명한 활성/비활성 구분 |
| 터치·키보드 | 주요 버튼 44px 이상, 보이는 포커스 |
| 장식 | 이미지·배너·마케팅 문구·애니메이션 없음 |

## 처리 계약

1. **원문:** 붙여넣기, UTF-8 텍스트 파일, 사용자가 선택한 Google Docs를 받는다. Drive 입력은 읽기만 하며 모든 탭과 지원되는 본문·표·각주를 읽는다.
2. **요약 1:** 전체 원문을 분석해 맥락과 사실 장부를 만들고, 원문 문장을 선택한다. 숫자·단위·부정·조건과 사용자 보존어를 보호한다.
3. **요약 2:** 요약 1에서 선택된 사실을 다시 필터링한다. 원문 장부·좌표를 유지하고, 요약의 질문이나 지시문을 새 사실로 해석하지 않는다. 보호 내용만 남았으면 무리하게 더 줄이지 않는다.
4. **복사:** 요약 결과를 복사해 Gemini·Codex·Claude 등에 직접 넣는다. 유료 API 호출·자동 웹 검색·결제는 앱 범위에 없다.
5. **저장:** 요약 2가 있으면 그것을, 없으면 요약 1을 통합 Google 문서 하나로 새 폴더에 저장한다. 원문은 덮어쓰지 않는다.
6. **목록:** 이 앱으로 만든 Drive 저장 폴더를 표로 조회한다. 전체 Drive 검색은 하지 않는다. 미완료 작업 폴더가 포함될 수 있음을 구분한다.

30~40기준쪽의 입력에서 약 5~10쪽을 목표로 하되 강제 상한으로 사실을 버리지 않는다. 1기준쪽은 1,500코드포인트이며 토큰 수나 실제 인쇄 쪽수와 동일하지 않다. 현재 토큰 수는 미측정이다.

## 구조와 무료 범위

```text
GitHub Pages: HTML / CSS / JavaScript 정적 파일
                  ↓
태블릿·모바일 브라우저: 요약 1 → 필터 요약 2
                  ↓ 명시적 연결·저장
사용자 Google Drive: 요약 문서·저장 목록
```

기본 요약은 모델·API 키·추론 서버 없이 실행한다. Drive를 제공할 때는 운영자가 GIS/Picker의 공개 client ID·제한된 API key·프로젝트 번호를 설정하고, 사용자는 자기 계정으로 파일별 권한을 허용한다. access token은 탭 메모리에만 둔다.

선택 LiteRT-LM 어댑터는 기기에서 호환 모델 파일을 선택한 경우에만 사용한다. 무거운 runtime은 기본 화면 다운로드와 분리한다. 이 선택 기능의 실기기 GPU·메모리·한국어 품질은 Beta 합격 증거로 아직 확보하지 않았다. 기본 브라우저 알고리즘은 기존 Python 엔진의 직접 이식판이 아니다.

## 저장·개인정보·실패

- 복사와 Drive 쓰기 직전에 기본 개인정보 패턴과 사용자가 지정한 단어를 가린다. 개인 사전·인증 토큰을 Git에 넣지 않는다.
- 원문 스냅샷과 근거 좌표를 보존하고 저장 직전에 Drive 원문 판을 다시 확인한다.
- 저장 요청의 응답 유실·재로그인·부분 실패를 장부로 확인한다. 생성 요청을 무조건 다시 보내거나 원격 편집을 덮어쓰지 않는다.
- 복구 보관은 선택이다. 보관을 끄면 탭 종료 뒤의 작업 복구를 보장하지 않는다.
- 측정하지 않은 의미 검사를 통과로 표시하지 않고, 원문·분량·후보 검토가 필요하면 부분 완료 상태를 유지한다.

## 오늘 Beta 검수

| 항목 | 완료 기준 |
|---|---|
| 한 화면 | 원문·요약 1·요약 2·실행 버튼·저장 목록, 화면 이동 0회 |
| 태블릿·모바일 | 가로 세 칸/좁은 세로 한 칸, 잘림 없는 입력과 읽기 |
| 기본 두 단계 | 합성 예제 전체 처리, 불필요 내용 축소, 마지막 조건·수치 보존 |
| 불가한 압축 | 보호 근거만 남았을 때 무음 삭제·허위 성공 없음 |
| 복사 | 선택한 요약과 실제 클립보드 내용 일치 |
| Drive | 실계정 연결·선택 원문 읽기·요약 저장·목록 조회·재열기 |
| 재시도 | 응답 유실·토큰 만료 후 중복 본문과 원문 덮어쓰기 없음 |

자동 테스트·빌드와 실제 계정/기기 검수를 구분한다. Google 실계정, 실제 태블릿 GPU, 실제 Pages URL 검수는 수행한 뒤에만 완료로 기록한다.

## Beta 이후

우선은 위 흐름의 버그 수정과 속도·가독성 개선만 한다. 멀티 에이전트·검색 보드·유료 AI 연결·대시보드·할 일·개인 균형 관리 등은 이 제품의 현재 범위에 넣지 않는다.
