# Beta 사용 시작·검수 순서

버전: `v0.1.0-beta.1` · 검수일: 2026-11-19 KST

## 1. 시작

**휴대폰·태블릿:** https://ai-agent-orchestrator.github.io/prompt-token-saver/ 를 연다. Google 연결이나 앱 설치 없이 예제로 시작할 수 있다. 앱처럼 쓰려면 Android Chrome 메뉴의 ‘앱 설치/홈 화면에 추가’, iPhone·iPad Safari 공유 메뉴의 ‘홈 화면에 추가’를 사용한다.

다음 명령은 일반 이용자에게 필요하지 않고 개발 PC에서 코드를 수정할 때만 사용한다.

개발 PC에 Node.js 24가 있는 경우:

```sh
git clone --branch claude/tablet-token-saver-2026-11-19 https://github.com/ai-agent-orchestrator/prompt-token-saver.git
cd prompt-token-saver/apps/tablet
npm ci
npm run dev
```

터미널의 Local 주소는 개발 PC 브라우저용이다. 다른 기기는 위 공개 HTTPS 주소를 사용한다. 현재 Pages source는 `claude/tablet-beta-pages` 루트이며 앱 코드와 모델 가중치·개인 자료를 섞지 않는다.

## 2. Drive 미연결: 가장 먼저 검수

`.env`와 Google 설정을 비워 둔다. 로그인하지 않고, 모델 파일도 선택하지 않는다.

| 순서 | 행동 | 기대 결과 |
|---|---|---|
| A1 | 앱 열기 | 다크 화면, 원문·요약 1·요약 2·실행 버튼·저장 목록 표시 |
| A2 | 예제 클릭 또는 공개 원문 붙여넣기 | 원문이 들어가고 글자 수 표시 |
| A3 | 요약하기 1 | 로그인 없이 가운데 결과 생성 |
| A4 | 필터로 요약하기 2 | 로그인 없이 오른쪽 결과 생성, 중요 수치·조건 보존 |
| A5 | 요약 1/2의 복사 | 표시한 요약과 붙여넣은 내용 일치 |
| A6 | Google 설정이 없는 상태로 Drive 저장 클릭 | 연결 설정 안내, 기존 두 요약 유지, 앱 전체 중단 없음 |
| A7 | 그 뒤 다시 결과 복사 | 연결을 하지 않아도 기존 결과를 계속 사용 가능 |

보호할 내용만 남았으면 요약 2가 더 짧아지지 않을 수 있다. 이때 중요 내용을 지워 성공으로 표시하지 않는지 확인한다.

## 3. Drive 연결: 선택 검수

운영자가 Google 공개 설정 세 개를 준비한 뒤에만 시행한다. 첫 검수에는 합성 예제나 공개 자료를 쓴다.

| 순서 | 행동 | 기대 결과 |
|---|---|---|
| B1 | Google 연결 후 문서 선택 | 선택한 문서만 읽고 입력 원문은 수정하지 않음 |
| B2 | 요약 1·요약 2 | A 경로와 같은 처리, 원문 전체 범위 확인 |
| B3 | Drive에 저장 | 최신 요약을 새 Google 문서로 저장, 완료 상태 표시 |
| B4 | 저장 목록 불러오기·열기 | 이 앱의 저장 폴더가 보이고 저장 결과 열림 |
| B5 | 로그인 취소·만료·재시도 | 안내 표시, 기존 요약 유지, 중복 본문·원문 덮어쓰기 없음 |
| B6 | 다른 기기에서 같은 계정으로 사용 | 저장한 Drive 결과 접근. 브라우저 작업·모델의 자동 동기화와 구분 |

## 4. 검수 기록

이 표는 실제 실행 후에만 갱신한다. 자동 테스트의 가짜 Google 응답을 실계정 성공으로 기록하지 않는다.

| 경로 | 환경 | 상태 | 비고 |
|---|---|---|---|
| Node 계약 테스트·정적 빌드 | 개발 PC, Node 24 | 통과: 70개 + 프로덕션 빌드 | 가짜 모델·가짜 Drive, 네트워크 호출 0건인 기본 두 단계 및 PWA PNG/manifest 시험 포함 |
| A1~A7 미연결 UI | 개발 PC 인앱 브라우저, production preview | 통과 | 원문 52,593자 → 8,202자 → 7,377자. 마지막 조건 보존, 복사 내용 일치, 미설정 저장 안내 후 결과 유지 |
| 태블릿/모바일 폭 | 브라우저 1024×768 / 390×844 | 통과: 가로 넘침 없음 | 각각 3열/1열, 실기기 검수와 구분 |
| B1~B6 연결 UI | Google 실계정·기기 | 검증 대기 | 운영자 설정 필요 |
| 실기기 GPU | 지원 태블릿 | 검증 대기 | 선택 기능 |
| 원격 HTTPS 주소 | GitHub Pages | 배포·기본 흐름 검수 통과 | 공개 주소에서 52,593자 → 8,202자 → 7,377자, 실제 복사·붙여넣기 일치 |
| 홈 화면 앱 설치·실기기 offline | Android / iOS | 검증 대기 | manifest·192/512 PNG·Apple touch icon·standalone metadata 준비 |

문제는 `행동 / 기대한 결과 / 실제 결과 / 재현 자료(합성·공개) / 기기·브라우저`로 기록한다. 오늘 검수한 뒤 발견 사항과 결과를 이 문서에 모아 다음 Beta 수정 범위를 정한다.
