# Brief Beta 확인 순서

1. 공개 주소를 열고 상단 ‘Beta · Brief 1.0’을 확인한다. 이전 버전이 남으면 기존 탭을 모두 닫고 다시 연다.
2. Google 로그인 없이 예제 → 요약하기 1 → 요약하기 2를 누른다. 본문이 각각 원문 길이의 1/3 이하, 2차가 더 짧은지 확인한다.
3. 원문·1차·2차 복사를 각각 누르고 붙여넣어 본문만 복사되는지 확인한다.
4. 판정 보드의 실패 이유·누락 목록을 확인한다. 문턱값 미리보기가 본문을 바꾸지 않는지, 엔진 재실행만 본문을 바꾸는지 확인한다.
5. 짧은 원문·모든 문장이 긴 원문·가짜 모델 실패에서 오류 문구가 본문 밖에 나오는지 확인한다.
6. 가리기 후 상한이 늘면 명시적 허용 전 복사·저장이 차단되는지 확인한다.
7. 운영자 설정이 있을 때만 실제 Google 가져오기·새 문서 저장·목록·원문 변경 감지를 검사한다. 기본 요약 검증과 구분해 기록한다.
8. 실제 Android/iOS 설치·오프라인·로컬 모델 GPU 검증은 별도로 진행한다.

자동 검사와 실제 계정/기기 검수 범위는 [구현 기록](BRIEF_IMPLEMENTATION.md)을 따른다.
