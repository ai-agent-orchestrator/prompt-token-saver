# Brief 1.0 구현·검증 기록

검증일: 2026-11-19. 사용자 개발안에 따라 브라우저 엔진을 정본으로 구현했다. Python 참조 구현은 공유 상수·fixture를 사용한다. 구 JS 조사 카드 엔진과 전용 테스트는 제거했다. Python compress는 호환 API로 유지한다.

## 실행한 검사

- Node.js 24: npm run check → 새 엔진·Drive·PWA·마스킹·모델 lifecycle 포함 71개 테스트, 프로덕션 빌드 통과.
- Python: python -m pytest -q → 335개 통과. Node subprocess를 통한 공유 fixture 10개의 1·2차 본문/상태 동일성 포함.
- 52,593자 합성 입력의 결정론 경로는 2초 이내 통과. 실제 시간은 아래 기록 참조.
- 모델 오류·빈 응답·초과 출력·타임아웃·중단, 숫자 변조·주체·부정·조건 누락, 원문 변경, 2차 감소 불가·마스킹 확장을 검증했다.
- 브라우저 요약·복사·Drive 산출물은 동일한 body-only 경계를 사용한다. 실제 브라우저·계정 E2E는 별도 기록하며 테스트 개수만으로 완료를 주장하지 않는다.

사용자 원문은 private fixture에만 두고 Git에서 제외한다. 앞선 1,020자 기록은 CRLF를 포함한 값이며 새 엔진 계약대로 LF 정규화한 길이는 1,006자다. 원문과 결과 본문 자체는 이 검증 기록에 싣지 않는다.

## 구현과 품질 검증의 구분

임계값 c1은 보정 전이며 A는 문자 3-gram 기반의 근거 대용 신호다. 실제 의미 함의·한국어 고유명 인식을 증명하지 않는다. 실제 LiteRT/Ollama 추론, 모델별 20개 이상 사람 라벨 품질 보정, 실제 Google 계정·태블릿 GPU·홈 화면 설치·오프라인 검수는 미수행이다. 기본 경로는 압축 발췌이고 모든 주제 보존을 보증하지 않으며 보드에 빠진 그룹·앵커를 표시한다.
