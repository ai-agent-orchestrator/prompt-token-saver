# Engine ver1 최종판

공개 저장소의 앱은 원래 `research_engine.py` ver1 선택기와 어휘 근거 검사기를 사용한다. 원본 출처는 `research-filter-board`의 `engines/ver1/research_engine.py`이며 이번 사용자 지시에 따라 공개판에 포함한다.

화면은 원문·요약 1·요약 2다. 요약 2는 최초 원문에서 ver1 문장 선택 비율을 낮춰 재실행하고, 실제 토큰이 줄어든 결과만 채택한다. 두 단계의 결과를 각각 복사/Drive 저장할 수 있다. 요약 1에서 바로 저장할 수 있다.

기존 공개 UI·개인정보 가리기·Drive 커넥터·PWA를 유지하며 LiteRT-LM 기본 모델 자동 준비를 연결했다. 문장 선택 비율을 토큰 상한으로 오해하지 않는다. ver1 어휘 검사는 의미 동등성/모든 사실 보존의 증명이 아니다.

검사: Node 101건, 실제 Pyodide에서 원본 ver1 선택/압축 검증. 합성 40문장 입력에서 1차 20문장·340토큰, 2차 204토큰, 새 수치 999원 주입 거절을 확인했다. 이 검사는 모델 생성이나 태블릿 속도를 측정한 것이 아니다.

개선판의 hybrid_engine·merge_guard·누적 리서치 로직과 상세 개발안은 공개판에 포함하지 않았다. 공개 main의 Pages Actions가 배포하며, 별도 배포 브랜치는 필요 없다. BUILD_INFO.json으로 배포된 엔진/화면/커밋을 확인할 수 있다.
